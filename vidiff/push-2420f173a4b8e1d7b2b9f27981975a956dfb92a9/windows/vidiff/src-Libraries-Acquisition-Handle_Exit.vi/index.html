Acquisition.lvlib:Handle Exit.vi

This VI handles the Exit Message for a DQMH Singleton module.

This VI determines if the message was received via the Stop Request or not. If the Exit message was received via the Request Event to Stop the module then there is no need to send the Stop Request again. If it was not, then the Stop Request needs to be fired so the Event Handling Loop can stop.

This VI also hides the Main.vi Front Panel, this is to ensure that the module stays in memory until the very last step in the Main.vi which is to close the front panel.
